# B2B iGaming Platform Scorecard - Vercel Deployment

Полнофункциональный инструмент оценки B2B iGaming платформ с поддержкой сохранения данных, экспорта и сравнения платформ.

## 🚀 Быстрый старт на Vercel

### Вариант 1: Deploy за 2 минуты (Рекомендуется)

1. **Откройте Vercel**: https://vercel.com/new

2. **Выберите Git provider** (GitHub/GitLab/Bitbucket)

3. **Импортируйте этот репозиторий**:
   - Если у вас еще нет репо, создайте его на GitHub
   - Загрузите файлы из папки `vercel-setup/` в корень репозитория

4. **Configure Project**:
   - Framework Preset: **Other** (static)
   - Build Command: оставить пусто или `echo 'No build needed'`
   - Output Directory: **.** (корень)

5. **Deploy**!

После успешного деплоя у вас будет URL вроде: `https://igaming-scorecard.vercel.app`

---

### Вариант 2: Deploy через Vercel CLI

```bash
# 1. Установите Vercel CLI
npm i -g vercel

# 2. Перейдите в папку проекта
cd vercel-setup

# 3. Deploy
vercel

# 4. Следуйте инструкциям в терминале
```

---

### Вариант 3: Deploy через GitHub Pages (Бесплатно)

1. Создайте репозиторий на GitHub: `igaming-scorecard`
2. Загрузите файлы из папки `vercel-setup/`
3. Перейдите в **Settings → Pages**
4. Выберите **Deploy from branch**: `main`, папка `/root`
5. Сохраните

Ваш сайт будет доступен по: `https://yourusername.github.io/igaming-scorecard`

## ✨ Функции

### 💾 Автоматическое сохранение
- Все оценки и комментарии сохраняются в `localStorage` браузера
- Данные сохраняются при каждом изменении
- При перезагрузке страницы все восстанавливается

### 📊 Dashboard
- Overall Platform Score (1-5)
- KPI: Critical Gaps, Strong Points
- Radar Chart и Bar Chart по разделам
- Ranked Section Scores

### 📋 Evaluation
- 65 критериев из 10 разделов
- Score dropdown: 1-Плохо, 2-Слабо, 3-Среднее, 4-Хорошо, 5-Отлично
- Адаптивные дескрипторы оценок (наводишь на Score → видишь что означает каждое значение)
- Автоматический расчет Weighted Score
- Поле для комментариев

### 🏆 Comparison
- Сравнение нескольких платформ
- Platform Ranking с медалями 🥇🥈🥉
- Side-by-side таблица оценок

### 📥 Export / Import
- **Export CSV**: для Excel/Google Sheets
- **Export JSON**: все данные для сохранения/архивирования
- **Import JSON**: загрузка сохраненных данных
- Copy-to-Clipboard: быстрое копирование в буфер обмена

## 🔧 Как использовать

### Оценивание платформы

1. **Введите название платформы** в поле "Platform name"
2. **Нажмите "Set"** → платформа добавится
3. **Перейдите на вкладку Evaluation**
4. **Заполните Score (1-5)** для каждого критерия
5. **Добавьте комментарии** если нужно
6. **Смотрите Dashboard** → автоматические расчеты

### Сравнение платформ

1. **На вкладке Comparison** введите название новой платформы
2. **Нажмите "+ Add"**
3. **Вернитесь на Evaluation**, переключитесь на новую платформу
4. **Заполните оценки**
5. **На Comparison** видите рейтинг и side-by-side таблицу

### Сохранение данных

**Автоматическое:**
- Все сохраняется в localStorage при каждом изменении
- Данные сохранаются в браузере (не на сервере)

**Ручное:**
- На вкладке Comparison → кнопка "💾 Save" → сохраняет в localStorage
- Кнопка "📥 Export" → скачивает JSON со всеми платформами
- Кнопка "📤 Import" → загружает JSON обратно

### Экспорт в Excel

1. **На вкладке Evaluation** нажмите "📥 CSV"
2. **Скопируйте данные** из модального окна
3. **Откройте Google Sheets** или Excel
4. **Вставьте данные** (Ctrl+V)
5. **Готово!**

## 🔒 Безопасность данных

⚠️ **Важно:**
- Данные хранятся только в localStorage браузера (на клиенте)
- **Не** отправляются на сервер
- При очистке кэша браузера данные удалятся
- Для постоянного хранения используйте Export → сохраняйте JSON файл

**Рекомендация**: Периодически экспортируйте данные в JSON для резервной копии.

## 🚨 Troubleshooting

### "Данные не сохраняются"
- Проверьте, не отключен ли localStorage в браузере
- Попробуйте другой браузер
- Очистите кэш браузера

### "Не вижу все 65 критериев"
- Разверните таблицу (Evaluation)
- Скролл вниз по таблице
- Все критерии должны быть видны

### "Export/Import не работает"
- Убедитесь, что скопировали полный JSON
- Проверьте, что JSON валидный (без ошибок)
- Используйте браузерную консоль (F12) для отладки

## 📈 Обновления

Если нужны новые критерии или изменения:

1. Отредактируйте `criteria` объект в коде
2. Добавьте новые дескрипторы в `scoreDescriptors`
3. Пересохраните на сервер

Все текущие оценки сохранятся благодаря localStorage.
